## api endpoint

https://zzz.cried.online/v1/upload

## upl a file

### (windows) PowerShell

-- powershell
curl.exe -X POST "https://zzz.cried.online/v1/upload" `
  -H "x-kim-api-key: KIMMY_API" `
  -H "x-kim-mode: underoos" `
  -H "x-filename: image.png" `
  -H "x-kim-visibility: public" `
  -H "Content-Type: image/png" `
  --data-binary "@image.png"

replace `KIMMY_API` with the api key provided at the top

+ required headers

| Header | Description |
|---|---|
| `x-kim-api-key` | api key provided at the top |
| `x-kim-mode` | mode is underoos |
| `x-kim-visibility` | keep this at public - only paid users can use other shit bla bla |
| `Content-Type` | files MIME type |
| `x-filename` | common sense |

+ js example

-- javascript
const response = await fetch(
  "https://zzz.cried.online/v1/upload",
  {
    method: "POST",
    headers: {
      "x-kim-api-key": process.env.KIMMY_API,
      "x-kim-mode": "underoos",
      "x-filename": "image.png",
      "x-kim-visibility": "public",
      "Content-Type": "image/png"
    },
    body: file
  }
);

const result = await response.json();

if (!response.ok) {
  throw new Error(result.error?.message ?? "Upload failed");
}

console.log(result.data);


**common sense:** keep the API key on your backend. never expose it in public frontend JavaScript

## common errors

| Error | Meaning |
|---|---|
| `missing_api_key` | apikey missing |
| `invalid_api_key` | wrong apikey |
| `invalid_upload_mode` | upload mode must be underoos |
| `file_too_large` | file exceeds 50 MiB |
| `checksum_mismatch` | provided SHA-256 checksum doesn't match |
| `storage_unavailable` | storage backend is unavailable |
